### Keptlive

I build tools for local and online communities.

**Local communities**

- [community-forum](https://github.com/keptlive/community-forum): a deliberation site where neighbors open topics, vote on statements anonymously and get notified when something new comes up. Built on Polis. Example: [croton.forum](https://croton.forum).

**Online communities**

- [Wildroot](https://github.com/wildroot-io): open infrastructure for decentralized naming, identity, communication and storage, so communities can run their own corner of the internet. I maintain it. The [project hub](https://wildroot-io.github.io) lists every project, including:
  - [hns-relay](https://github.com/wildroot-io/hns-relay): a Nostr relay that can limit posting to people whose names sit under a community's own domain.
  - [hns-nostr](https://github.com/wildroot-io/hns-nostr): look up a person's Nostr identity from a Handshake name or NIP-05 address, with proofs.
  - [wildroot-web3-resolution](https://github.com/wildroot-io/wildroot-web3-resolution): resolve names across Handshake, DNS, IPFS, ENS, Nostr and other networks.

**Other tools**

- [vin-mcp](https://github.com/keptlive/vin-mcp): VIN decoding, recalls and vehicle data through MCP and a REST API, hosted at [mcp.vin](https://mcp.vin).
- [contextwire-mcp](https://github.com/keptlive/contextwire-mcp): web search, research and page extraction for MCP clients.
- [cx-bridge](https://github.com/keptlive/cx-bridge): send tasks between Claude Code and Codex and read the results back.

**Experiments**

- [systems-modeler](https://github.com/keptlive/systems-modeler): an experimental system dynamics modeler with a library of 1,000 example models. For serious work, use [Simlin](https://simlin.com).
- [plate-tracker](https://github.com/keptlive/plate-tracker): a road-trip game for spotting license plates from all 50 states. [Play it](https://keptlive.github.io/plate-tracker/).
