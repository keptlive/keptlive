### Keptlive

I build small, practical tools for AI agents, local communities and open infrastructure.

**Wildroot.** I maintain [Wildroot](https://github.com/wildroot-io), open infrastructure for decentralized naming, identity, communication and storage. Its projects live in the [wildroot-io](https://github.com/wildroot-io) organization, and the [project hub](https://wildroot-io.github.io) lists them all.

**Tools for AI agents**

- [vin-mcp](https://github.com/keptlive/vin-mcp): VIN decoding, recalls and vehicle data through MCP and a REST API. Hosted at [mcp.vin](https://mcp.vin).
- [contextwire-mcp](https://github.com/keptlive/contextwire-mcp): web search, research and page extraction for MCP clients, from [ContextWire](https://contextwire.dev).
- [cx-bridge](https://github.com/keptlive/cx-bridge): send tasks between Claude Code and Codex and read the results back.

**Community**

- [community-forum](https://github.com/keptlive/community-forum): a community deliberation site built on Polis, with topics, anonymous voting and notifications. Example: [croton.forum](https://croton.forum).

**Experiments**

- [systems-modeler](https://github.com/keptlive/systems-modeler): an experimental system dynamics modeler with a library of 1,000 example models. For serious work, use [Simlin](https://simlin.com).
- [plate-tracker](https://github.com/keptlive/plate-tracker): a road-trip game for spotting license plates from all 50 states. [Play it](https://keptlive.github.io/plate-tracker/).
