### Keptlive

I build tools for local and online communities, plus infrastructure for AI agents and open protocols.

**Local communities**

- [community-forum](https://github.com/keptlive/community-forum): a deliberation site where neighbors open topics, vote on statements anonymously and get notified when something new comes up, with an optional WhatsApp voting bridge. Built on Polis. Live at [croton.forum](https://croton.forum).

**Online communities**

- [Wildroot](https://github.com/wildroot-io): open infrastructure for decentralized naming, identity, communication and storage, so communities can run their own corner of the internet ([wildroot.io](https://wildroot.io)). The [project hub](https://wildroot-io.github.io) lists every project, including:
  - [wildroot-web3-resolution](https://github.com/wildroot-io/wildroot-web3-resolution): resolve and verify names across Handshake, DNS, IPFS, Arweave, ENS, Nostr, AT Protocol and Tor.
  - [hns-relay](https://github.com/wildroot-io/hns-relay): a Nostr relay with NIP-05 write admission for names under a community's own domain.
  - [hns-nostr](https://github.com/wildroot-io/hns-nostr): look up a person's Nostr identity from a Handshake name or NIP-05 address, with chain and signature proofs.
  - [hns-odoh](https://github.com/wildroot-io/hns-odoh): Oblivious DNS-over-HTTPS (RFC 9230) for Handshake names.
  - [sia-ipfs-bridge](https://github.com/wildroot-io/sia-ipfs-bridge): serve content-addressed IPFS data stored on Sia with a trustless CAR gateway ([pinthis.cloud](https://pinthis.cloud)).

**Agent & developer tools**

- [cx-bridge](https://github.com/keptlive/cx-bridge): send tasks, resumable sessions and inline messages across Claude Code, Codex, Antigravity and ACP/custom agent frameworks, with live hooks and a stdio MCP server.
- [burndeck](https://github.com/keptlive/burndeck): an ESP32 desk display for Claude Code — live sessions, subagents, rate-limit burn, tap-to-answer prompts and a signed LAN UDP protocol. [Web flasher](https://keptlive.github.io/burndeck/).
- [vin-mcp](https://github.com/keptlive/vin-mcp): VIN decoding, recalls and vehicle data through MCP and HTTP APIs, hosted at [mcp.vin](https://mcp.vin).
- [qr-mcp](https://github.com/keptlive/qr-mcp): styled SVG QR codes (URLs, Wi-Fi, vCards, gradients and center logos) and optional AI QR art for MCP clients.
- [contextwire-mcp](https://github.com/keptlive/contextwire-mcp): web search, academic research and page extraction for MCP clients ([contextwire.dev](https://contextwire.dev)).

**Modeling & web apps**

- [systems-modeler](https://github.com/keptlive/systems-modeler): an interactive system dynamics modeler with a curated library of 1,000 XMILE models, native simulation and MCP sensitivity tools, live at [stockandflow.live](https://stockandflow.live). Built alongside [Simlin](https://simlin.com).
- [plate-tracker](https://github.com/keptlive/plate-tracker): a road-trip game for spotting license plates from all 50 states. [Play it](https://keptlive.github.io/plate-tracker/).
